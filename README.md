# AFI Command

afi_admin（非公開）の状況をスマホで見るための画面です。GitHub Pages で配っています。

- このリポジトリにあるのは画面のファイルだけです。実データは、開いた端末で設定したトークンを使って、非公開リポジトリから GitHub API で読みます
- トークンは開いた端末のブラウザにだけ保存されます。このリポジトリには入りません
- トークンが無いときは、架空のデモデータを表示します

元のファイルは afi_admin の `mobile/` にあります。画面を直すときは afi_admin 側を直し、このリポジトリにコピーしてください（PC で使う `serve.py` はここには置きません）。
